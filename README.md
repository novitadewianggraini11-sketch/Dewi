# Website Toko Online (GitHub Pages Ready)

File ini berisi struktur proyek website platform jual beli barang yang sudah siap diunggah ke GitHub Pages.

## Isi File:
- `index.html` : Halaman utama website e-commerce responsif dan modern.

## Cara Menggunakan di GitHub Pages:
1. Ekstrak file ZIP ini di komputer Anda.
2. Buat repositori baru di GitHub (misal: `toko-online`).
3. Upload file `index.html` ke repositori tersebut.
4. Buka tab **Settings** > **Pages** di repositori GitHub Anda.
5. Pada bagian **Branch**, pilih `main` atau `master`, lalu klik **Save**.
6. Website Anda akan aktif dalam kurun waktu 1–2 menit!
